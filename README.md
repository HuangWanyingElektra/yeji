# 页迹 · Yeji

每天读一页，页页留痕迹。

一个轻量的读书打卡工具，帮你在读一本难啃的书时，留下进度和思考。

## 功能

- **多档案**：一台设备可以建多个档案，互不干扰
- **书架管理**：在读 / 已读完分开存放，卡片显示累计与连续打卡天数
- **每日打卡**：今天读到第几页、心情、摘抄（可标记重点）、随手写几句、问题、阅读计时
- **阅读记录月历**：圆点标记打卡日，点开可看当天原文
- **页数校验**：忘记更新页数时会提醒，避免记录失真
- **数据备份**：一键导出 / 导入全部数据

## 使用

打开 <https://huangwanyingelektra.github.io/yeji/>

## 关于数据

所有数据保存在**你自己浏览器的本地存储**（localStorage），不会上传到任何服务器。

这意味着：

- 你的打卡内容、摘抄、批注，只有你自己看得到
- 换设备、换浏览器、清理浏览器数据，记录不会自动跟着走 —— 请用页面内的「导出全部数据备份」功能自行备份
- 同一个网址下，每个人看到的是各自独立的书架

## 技术

单个 HTML 文件 + 原生 JavaScript，无框架、无依赖、无需构建。
